# Опора — сайт психологической поддержки

Откройте `index.html` в браузере. Внешних зависимостей, шрифтов, аналитики и сетевых запросов нет. Каталог ограничен Челябинском: очные встречи и демонстрационные онлайн-консультации указаны для Челябинска.

Также можно запустить из этой папки: `python -m http.server 8000 --bind 127.0.0.1`, затем открыть http://127.0.0.1:8000.

Реализованы адаптивный каталог, совместные фильтры темы/формата/цены, состояние без результатов, карточки сведений, модальная форма записи, форма обращения с HTML-валидацией, FAQ и экстренный номер 112 для России. Формы не отправляют данные, не сохраняют их в localStorage и очищают поля после проверки. Модальное окно закрывается кнопкой и Escape.

Все специалисты вымышлены. Цены и варианты времени демонстрационные. Проверка квалификации, реальная запись и отправка обращений не реализованы. Для запуска сервиса необходимы реальные анкеты с подтверждающими сведениями, сервер бронирования с проверкой доступности, защищённая обработка обращений и опубликованные условия обработки данных. Не выдавайте прототип за работающую службу поддержки.
